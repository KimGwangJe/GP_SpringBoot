### 📢 프로젝트 소개
이 프로젝트는 호서대학교 학생들을 위한 챗봇 서비스입니다.

학생들이 기존의 호서대학교 포털사이트를 이용하는 데 어려움을 느낀다는 것을 알게 되어 아이디어를 얻을 수 있게 되었습니다.

학생들은 학교에 대해 궁금한 것이 있다면 챗봇에 질의를 하여 정보를 얻을 수 있습니다.

챗봇은 다음과 같은 질문의 의도를 파악할 수 있습니다.

1️⃣ 사용자가 수강한 강의 기반 강의 추천 : 사용자가 수강한 강의 데이터를 기반으로 맞춤 강의를 추천합니다.

2️⃣ 질문에 기반한 강의 추천 : 사용자가 질문에 입력한 키워드를 추출하여 강의를 추천합니다.

3️⃣ 졸업 요건 확인 : 졸업 요건을 분석해 개인 맞춤형 커리큘럼을 제안합니다.

4️⃣ 학교 시설 안내 : 캠퍼스 내 시설 위치 정보를 제공합니다.

### 🙋‍♂️ 역할
1) Spring Security와 JWT를 이용해 로그인 기능을 구현하였습니다.

2) ChatGPT API를 사용하여 정의되지 않은 의도의 질문에 대한 답변을 생성하는 제공받아 사용자에게 전달하였습니다.

3) Redis를 활용한 캐싱으로 자주 요청되는 API의 데이터 조회 응답 시간을 단축하고 데이터베이스 부하를 줄였습니다.

4) Docker를 사용해 컨테이너화하여 다양한 환경에서 애플리케이션 실행을 용이하게 했습니다. 최종적으로 애플리케이션을 AWS에 배포하여 클라우드 환경에서 확장성과 가용성을 확보하고 실제 운영 환경에서도 안정적인 성능을 제공할 수 있도록 했습니다.

### 👨🏼‍💻 성과 & 배운점
1) AISW중심대학사업단 최우수상.

2024년 호서대학교 컴퓨터공학부 졸업작품 발표회에서 최우수상을 수상하며 프로젝트의 성과를 인정받았습니다.

캐싱 기능을 구현하며 응답 시간을 대폭 단축했습니다. 이를 통해 데이터베이스 부하를 줄였습니다.

3) 클라우드 환경 운영 경험

Docker로 컨테이너화한 애플리케이션을 AWS에 배포하며 다양한 환경에서의 실행 가능성과 클라우드 환경에서의 확장성을 경험했습니다.
